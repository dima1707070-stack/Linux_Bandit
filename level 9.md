# Bandit Level 9 - Level 10

## Цель
Найти пароль для следующего уровню. Пароль находится в файле под названием `data.txt`
## Трудность
Нужный пароль находится среди нескольких читаемых строк, перед которыми стоит несколько символов "=".
## Ход решения
1. Подключился к уровню по SSH:
```
ssh bandit9@bandit.labs.overthewire.org -p 2220
```
2. Сначала выводим все файлы командой `ls`, выводит единственный текстовый файл `data.txt`. Вывод командой `cat` засоряет терминал нечитаными символами.

Я нашел два варианта решения задачи:

1 вариант. Используем новую команду `strings`, которая выводит последовательности печатных символов из файла, и задаем ей количество символов, строки которую
хотим найти, пройдя прошлые уровни, можно посчитать сколько примерно символов используется в пароле, около 30, итоговая команда выглядит так:
string -30 data.txt, после чего получаем наш пароль

2 вариант. Также используем команду `strings`, но добавляем к ней уже знакомую команду `grep`, которая помогает найти нужные строки по заданным словам, мы знаем, что перед паролем стоит символ "=", поэтому пишем такую команду: `strings Data.txt | grep "="`, после чего выводится несколько строк где используется
"=" среди которых есть пароль.

## Использованные команды
-`strings`: вывод читаемых строк из бинарного файла

-`|`: передача вывода первой команды на вход второй

-`grep "="`: поиск строк содержащих "="

## Что понял
Научился работать с бинарными файлами: извлекать из них читаемый текст командой `string` и фильтров результат через `grep`.
## Результат
Доступ к Level 10 получен. Пароль в репозитории не публикуется.
