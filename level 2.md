# Bandit Level 2 - Level 3

## Цель
Найти пароль для следующего уровня. Он хранится в файле с пробелами в имени в домашней директории.

## Трудность
Имя файла содержит пробелы и начинается с двух дефисов. Пробелы разбивают команду на несколько аргументов, а дефисы в начале воспринимаются как опции команды.

## Ход решения
1. Подключился к уровню по SSH:
`ssh bandit2@bandit.labs.overthewire.org -p 22202`. Посмотрел точное имя файла:
`ls`. Первые попытки без учета дефисов или без кавычек привели к ошибкам No such file or directory и unexpected argument.
4. Прочитал файл, указав путь через ./ и взяв имя в кавычки:
cat ./"--spaces in this filename--".

## Использованные команды
- `ls`: показывает содержимое папки и точное имя файла
- `cat`: выводит содержимое файла
- ./ перед именем: указывает путь, чтобы дефисы не считались опциями
- кавычки: объединяют имя с пробелами в один аргумент

## Что понял
Сначала нужно смотреть точное имя файла через ls. Если имя содержит пробелы, его берут в кавычки, а если начинается с дефиса, перед ним ставят ./.

## Результат
Доступ к Level 3 получен. Пароль в репозитории не публикуется.
