# Bandit Level 10 - Level 11

## Цель
Найти пароль для следующего уровню. Пароль находится в файле под названием `data.txt`
## Трудность
Нужный пароль находится в файле Data.txt, который содержит данные, закодированные в base64
## Ход решения
1. Подключился к уровню по SSH:
```
ssh bandit10@bandit.labs.overthewire.org -p 2220
```
2. Сначала выводим все файлы командой `ls`, выводит единственный текстовый файл `data.txt`. Выводим командой `cat`, убеждаемся, что это кодировка base64, после чего декодируем файл командой: `base64 -d Data.txt`


## Использованные команды
-`ls`: показывает содержимое папки

-`cat`: выводит содержимое файла

-`base64 -d`: декодирует файл, который закодирован в формате base64

## Что понял
Научился пользоваться утилитой для кодирования данных: `base64` и декодирования: `base64 -d`
## Результат
Доступ к Level 11 получен. Пароль в репозитории не публикуется.
