# Bandit Level 11 - Level 12

## Цель
Найти пароль для следующего уровню. Пароль находится в файле под названием `data.txt`
## Трудность
Нужный пароль находится в файле Data.txt, все буквы в этом файле зашифрованы с помощью rot13 - каждая буква заменена на букву, находящуюся
на 13 позиций дальше в алфавите. Этот шифр называется цезарь.
## Ход решения
1. Подключился к уровню по SSH:
```
ssh bandit11@bandit.labs.overthewire.org -p 2220
```
2. Сначала выводим все файлы командой `ls`, выводит единственный текстовый файл `data.txt`. Выводим командой `cat`, нам выдают строку
случайных символов, по условию мы знаем, что строка зашифрована с помощью rot13, поэтому пишем следующее команду:
cat Data.txt | tr a-zA-Z n-za-mN-ZA-M

## Использованные команды
-`cat Data.txt`: выводит содержимое файла Data.txt

-`| `: передает результат первой команды второй

-`tr`: заменяет символы

-`a-zA-Z`: английские буквы в нижнем и верхнем регистре

-`n-za-mN-ZA-M`: задает соответствие букв для расшифровки rot13


## Что понял
Научился расшифровывать файлы которые используют шифр цезаря 
## Результат
Доступ к Level 11 получен. Пароль в репозитории не публикуется.
