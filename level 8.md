# Bandit Level 8 - Level 9

## Цель
Найти пароль для следующего уровню. Пароль находится в файле под названием File.txt
## Трудность
Нужный пароль находится среди других паролей. В условии есть подсказка, что пароль который нужен повторяется только один раз.
1. Подключился к уровню по SSH:
```
ssh bandit8@bandit.labs.overthewire.org -p 2220
```
2. По условию задания сказано, что пароль хранится в текстовом файле и повторяется только один раз, поэтому будем использовать новую команду `sort`.
Которая выводит строки файла в отсортированном порядке, потом добавляем uniq -u, которая печатает только те строки, которые встретились один раз



## Что понял
Изучил новую команду: `grep`, с помощью которой можно находить нужную информацию по заданным словам

## Результат
Доступ к Level 8 получен. Пароль в репозитории не публикуется.
